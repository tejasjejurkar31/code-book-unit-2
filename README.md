Unit II – Inheritance Programs

Program| Description
1. Basic Single Inheritance| Shows how Student inherits properties and functions from Person.
2. Protected Member Access| Demonstrates accessing protected members in a derived class.
3. Public vs Private Inheritance| Shows the difference between public and private inheritance.
4. Multilevel Inheritance| Demonstrates Person → Employee → Manager inheritance.
5. Hierarchical Inheritance| Shows Car and Bike inheriting from Vehicle.
6. Multiple Inheritance| Demonstrates Student inheriting from Academic and Sports.
7. Multiple-Inheritance Ambiguity| Shows how ambiguity occurs and is resolved using "::".
8. Constructor & Destructor Order| Demonstrates the order of constructor and destructor execution.
9. Parameterized Base Constructor| Shows how a derived class calls a parameterized base constructor.
10. Function Overriding| Demonstrates overriding a virtual function using "override".
11. Abstract Class| Shows a Shape class with a pure virtual "area()" function.
12. Virtual Base Class| Demonstrates virtual inheritance to solve the diamond problem.
13. Friend Class| Shows how a friend class can access private members.
14. Nested Class| Demonstrates a class defined inside another class.
15. Vehicle Rental System| Calculates rental charges using Vehicle, Car and Bike classes.
16. Employee Payroll System| Calculates salaries using inheritance and polymorphism.

Objective

To understand the concepts of inheritance, polymorphism, abstraction, encapsulation, constructors, destructors, and other OOP features in C++.
