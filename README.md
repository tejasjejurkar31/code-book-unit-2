# Unit II – List of Programs

| Program | Brief Description |
|---------|-------------------|
| **1. Basic Single Inheritance** | Demonstrates how a `Student` class inherits data members and member functions from a `Person` base class, showing code reuse through inheritance. |
| **2. Protected Member Access** | Shows how a derived class can directly access `protected` members of its base class while keeping them hidden from outside objects. |
| **3. Public vs Private Inheritance** | Compares `public` and `private` inheritance by showing how the accessibility of inherited members changes in the derived class. |
| **4. Multilevel Inheritance** | Demonstrates a three-level hierarchy (`Person → Employee → Manager`) where each level extends the previous class. |
| **5. Hierarchical Inheritance** | Shows how `Car` and `Bike` inherit common properties and functions from a single `Vehicle` base class. |
| **6. Multiple Inheritance** | Demonstrates a `Student` class inheriting from both `Academic` and `Sports` classes. |
| **7. Multiple-Inheritance Ambiguity** | Demonstrates ambiguity when two base classes contain functions with the same name and resolves it using the scope-resolution operator (`::`). |
| **8. Constructor & Destructor Order** | Shows constructors executing from Base to Derived and destructors executing in reverse order. |
| **9. Parameterized Base Constructor** | Demonstrates calling a parameterized base-class constructor using a constructor initializer list. |
| **10. Function Overriding** | Demonstrates overriding a virtual function using `override` for run-time polymorphism. |
| **11. Abstract Class** | Demonstrates an abstract `Shape` class with a pure virtual `area()` function implemented by `Rectangle` and `Circle`. |
| **12. Virtual Base Class & Diamond Inheritance** | Uses virtual inheritance to solve the diamond inheritance problem by preventing duplicate copies of the `Person` base class. |
| **13. Friend Class** | Demonstrates how a friend class (`Auditor`) can access private members of another class (`Account`). |
| **14. Nested Class** | Demonstrates defining `Department` inside `University` and accessing it using `University::Department`. |
| **15. Vehicle Rental System** | Mini-project using `Vehicle`, `Car`, and `Bike` classes to calculate rental charges and display details. |
| **16. Employee Payroll System** | Mini-project using an abstract `Employee` class with `PermanentEmployee` and `ContractEmployee` classes to calculate salaries through polymorphism. |
